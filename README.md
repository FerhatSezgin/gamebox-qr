## 🚀 Bilgisayarda Nasıl Açılır?

1. Masaüstünüzdeki `gamebox_qr` klasörüne girin.
2. **`index.html`** dosyasına çift tıklayın; menü doğrudan tarayıcınızda açılacaktır.

## 🌐 Müşterilerin Okutması İçin İnternete Yükleme (Ücretsiz - 0 TL)

1. [app.netlify.com/drop](https://app.netlify.com/drop) adresine girin.
2. `gamebox_qr` klasörünü farenizle tutup sayfaya bırakın.
3. 10 saniye içinde size `https://gamebox-cafe.netlify.app` gibi bir site linki verir.
4. Bu linki `qr-generator.html` sayfasına yazıp masalarınız için hazır QR kartlarını yazdırabilirsiniz!
